ArioClip

AI-powered video clipping tool. Drop a YouTube link — AI finds viral moments, generates vertical clips with face-tracking, and syncs captions.

View on GitHub Quickstart

Features

Everything you need to turn long videos into platform-ready shorts.

🎯

AI Segment Selection

Pydantic AI analyzes transcripts to pick 3–7 viral moments with virality scoring.

🎭

Face-Aware Cropping

MediaPipe → OpenCV DNN → Haar cascade fallback chain keeps faces centered.

📝

Word-Synced Subtitles

AssemblyAI word timestamps rendered as styled, animated captions.

📊

Virality Scoring

Each clip scored on hook, engagement, value & shareability (0–100).

🎨

Caption Templates

Customizable animated templates with multiple styles to match your brand.

🎬

Transition Effects

Optional intro/outro effects between clips for a polished finish.

🖼️

B-Roll Overlays

Pexels integration for stock footage overlays to enhance visual appeal.

📤

YouTube Upload

Multi-channel OAuth upload directly from the app to your YouTube channels.

⚡

Real-Time Progress

SSE stream from worker to frontend — see every step as it happens.

Processing Pipeline

From raw video to finished shorts in minutes.

📹 Input → 🤖 AI Analysis → 🎬 Render → 📱 Export YouTube URL or upload · AssemblyAI transcription · Pydantic AI selection · MoviePy rendering

Quickstart

Get up and running in minutes.

git clone https://github.com/Samuv5/ArioClip.git Clone the repo
cp .env.example .env Configure API keys
./install.sh Install dependencies
docker compose up -d --build Or use Docker
./start-local.sh Start all services

Start Clipping

Self-host your own AI video clipping pipeline. No subscriptions, no limits.
