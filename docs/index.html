Features

A complete clipping pipeline

From download to export — every step optimized for quality and speed.

Gemma-3 AI Selection

Google Gemma-3 4B runs locally via llama.cpp. Improved prompt engineering with concrete examples — selects 2–5 viral-worthy segments with per-clip scoring.

Face-Aware Cropping

MediaPipe → OpenCV DNN → Haar cascade fallback chain keeps faces perfectly centered in every 9:16 frame.

Word-Synced Captions

WhisperX word-level timestamps rendered as animated captions. Each word appears in sync with the speaker's voice.

7 Caption Templates

7 animated styles — default, minimal, karaoke, pop, fade, typewriter, scale in. Change styles without re-rendering.

Sub-Progress Tracking

Real-time SSE with granular sub-progress bars. See exact step (transcription → AI → rendering clip N/M) with elapsed time and ETA estimates.

Smart Error Handling

Every failure mode gets a human-readable message with an error code. No more cryptic stack traces — categorized as download, transcription, analysis, or clip errors.

GPU Memory Management

Intelligent VRAM orchestration on 4GB cards — stops llama-server before WhisperX/ffmpeg, restarts for AI analysis. No crashes.

B-Roll Overlays

Pexels integration for context-aware stock footage overlays — automatically adds B-roll to enhance visual retention.

YouTube Upload

Multi-channel OAuth upload directly from the app. Export clips and publish without leaving the dashboard.

Smarter AI

Engineered for quality picks

The AI prompt was rewritten from scratch to eliminate bad clips and maximize viral potential.

Before (generic)

  • Abstract instructions, no concrete examples
  • Picked intros & sponsor reads
  • Only scanned the first 3 minutes
  • Content-neutral (accepted vague rambling)
  • Clips often made no sense standalone

After (grounded)

  • Concrete GOOD PICK and BAD PICK examples
  • Forces full-timeline coverage (max 1 in first 20%)
  • Expands short moments with nearby context
  • Requires self-contained clarity per clip
  • Duration rules: 90-150s preferred, 60-180s max
